## 渲染

```bash
# 一键把 figures/*.svg 渲染为 preview/*.png（用本机 Chrome 无头模式）
cd figures && python _render.py
```

`_render.py` 按 SVG 的 viewBox 自动算出 1.6 倍窗口尺寸，输出到 `preview/`。

## 校验

```bash
python ~/.workbuddy-ai/skills/diagram-drawing-plus/scripts/diagram_helper.py validate --svg figures/fXX.svg
```

注意：堆叠条形（f04 / f06）、时间轴分段（f03）、突破叠加虚线（f02）等**故意贴合**，会被校验器报"间距 < 5px"——属于设计而非遮挡。
