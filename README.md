# 《凡人修仙传·人生模拟器》

> 一个由 AI 扮演「天道」主持的中文文字修仙人生模拟器 · 规则全集
>
> An AI-run text life simulator set in the world of *A Record of a Mortal's Journey to Immortality*.

玩家只负责做决定，其余交给天意：出身、灵根、寿元、机缘、天劫，全在一颗 D100 骰子里。

## 这是什么

《凡人修仙传·人生模拟器》是一套面向大语言模型的跑团式规则集。AI 在游戏中担任唯一主持人**【天道】**，同时负责两件事：

- **规则执法**：投骰、算数、更新面板，公示每一次判定，绝不暗改数值；
- **剧情演绎**：扮演修仙界的所有 NPC、妖兽与宗门，信息分层释放，绝不替玩家做决定。

玩家从一名凡人起步，在人界【天南】掷骰求生，一路走过炼气、筑基、结丹、元婴、化神，直至飞升。核心基调是"凡人流"式的冷酷：

> 修仙如逆水行舟：资质、资源、机缘三者缺一，便可能困死一境，寿尽坐化。

### 四份文档怎么配合

优先级：**速查卡 ＞ 补全版 ＞ 初版**。

1. `天道速查卡.md`：每回合常驻的压缩规则，开局贴一次即可，是玩游戏的**唯一入口**；
2. `…-补全版.md`：主文档。**不要整篇粘贴**——按速查卡文末索引按需读取单章（例如"读第二十六章 26.3"）；
3. `…-灵界仙界篇.md`：续册，分三级上锁。人界存档不得朗读、引用或暗示其中条文；玩家飞升后逐级解锁；
4. `…-规则总纲.md`：初版 25 章，仅在开局选择「纯原文模式」时使用。

> 开局时由玩家选择**启用补全**（推荐，以补全版为准）或**纯原文**（只用初版，附录一不生效）。

## 快速开始

### 方式一：Cursor（推荐）

1. 用 [Cursor](https://cursor.com) 打开本目录（文件夹名 `cursor-凡人修仙传` 即由此而来）；
2. 在对话中说：**「读取《天道速查卡.md》，按『四份文档的使用规则』准备开局」**；
3. 跟随【天道】引导完成开局：模式选择 → 出身 → 难度 → 开局年 → 灵根 → 系统 → 面板；
4. 之后每回合用【】申报一件主要行动，等待天道投骰与结算。

### 方式二：任意支持文件读写的 AI 助手

Claude Code、OpenCode 等能够访问本目录的 Agent 均可直接使用；也可以把 `天道速查卡.md` 贴进支持长上下文的对话，再按需补充其余文档。

### 使用提醒

- **不要一次性投喂全部文档**。补全版约 286 KB，正确用法是"速查卡常驻 + 按索引读单章"；
- `天道速查卡.md` 的「文件位置」一节写死了本地路径 `D:\cursor-凡人修仙传\`，克隆到其他位置后请改为实际路径，或让 AI 以实际目录为准；
- 想体验完整规则，开局时选「启用补全」。

## 配套 Skill：说人话

`.cursor/skills/shuorenhua` 是一个 Cursor Skill，用于**审稿与去 AI 味**：在保留事实、术语与责任主体（谁做什么）的前提下，清理包装语、翻译腔与冗余表达；支持中英文、多种编辑范围（`structural` / `bounded` / `in-place` 等），以及"只标问题、不改写"的标注模式。配合本模拟器使用，可润色 AI 生成的小说正文，让文字更像人写的。
