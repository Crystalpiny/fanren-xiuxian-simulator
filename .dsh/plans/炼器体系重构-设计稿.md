# 炼器体系按丹道体系重构方案（设计稿）

**总则**：器道与丹道同源同构，共用「熟练度—品阶—火候—理论」一套骨架。命名与丹道逐位平行，数值一律沿用丹道口径（沿用六档熟练度、五档器方难度、成功率封顶 80%、不新造骰子）。

## 一、器道境界体系（六档，与丹道逐位平行）

| 器道 | 对应丹道 | 熟练度 | 能力标志 |
|---|---|---|---|
| 器徒 | 丹徒 | 0~20 | 只炼凡器下品，技艺加成 +0 |
| 器师 | 丹师 | 21~40 | 凡器中品，＋5% |
| 大器师 | 大丹师 | 41~60 | 凡器上品，＋10%，一料多成 +1 |
| 器道宗师 | 丹道宗师 | 61~80 | 极品可期，＋15%，可炼灵器 |
| 器圣 | 丹圣 | 81~100 | 极品常驻，＋20%，可越阶炼器 |
| **器王** | **丹王** | **101~150（达成值 150）** | **出器必极品、免投品阶骰**，称号入档 |

**晋级条件**（照搬丹道登神梯）：100 后普通炼器不涨熟练度，只认**炼成某类法器最顶级者**——练气 +1／筑基 +2／结丹 +3／元婴 +5（按件）。节点平行：110 锤炼通明（控温 T＋5）｜120 料性了然（器方难度项 ＋5%、减料惩罚缓）｜130 一料多成（基准 3→4）｜140 器鸣引客（销路与声名）｜150 器王。150 封顶。

## 二、器道理论五要

**器方·料性·火候·器诀·器纹**（对应丹方·药性·火候·丹诀·丹纹）：

- **器方**：载主材／辅材／器引／淬火液与工序，难度五档（易＋5／常 0／难 −10／极难 −20／逆天 −30），同丹方。
- **料性**：五行（金木水火土）＋三质（刚／柔／灵载），相生相克，对应药性。
- **火候**：炉温曲线与锤炼节奏（文火慢炼、武火急锻、千锤定音），投控温 T，对应控火 T。
- **器诀**：手诀、锤法、养器诀，统摄全程，对应丹诀。
- **器纹**：铭入器体的微型阵纹（丹纹是药力 ×1.3，器纹是威能 ＋一档、可越一境）。

**关系链**：器方定骨架 → 料性定相合 → 火候定成败 → 器纹定品阶 → 器诀统全程。缺主材或缺器引不开炉，不投骰。

## 三、炼器标准流程（七步）

| 步骤 | 关键要点 | 失败形态 | 补救 |
|---|---|---|---|
| 备料 | 验料龄、辨料性 | 料性相克看不穿 | 验货判定／换料 |
| 熔炼 | 化料去杂 | 杂质未尽 | 降等重熔 |
| 合料 | 主辅相合 | 分层不匀 | 添器引调和 |
| 塑形 | 定形定性 | 裂、走形 | 趁热回炉一次 |
| 铭纹 | 器纹入体 | 纹溃 | 洗纹重铭（−10%） |
| 出炉 | 开锋、点睛 | 哑器（无灵性） | 温养数月 |
| 器劫 | 见第六节 | 毁器 | 无 |

**失败总判**：投 D100，1~60 废器（主材损，回收三成辅材）；61~90 劣器（威能三成）；91~100 炸炉（扣气血、毁炉，按伤势规则结算）。

## 四、法器品阶：五境九品

**凡器 → 灵器 → 宝器 → 仙器 → 神器**，每境九品，品号越小越高。

- 与现行「品阶」四等对位：下品＝七至九品｜中品＝四至六品｜上品＝一至三品｜极品＝破境之器（必带器纹）。
- 与现行法器阶梯归位：法器、符宝→凡器／灵器；真宝、法宝、本命法宝、古宝→宝器；仿通天灵宝、通天灵宝→仙器；玄天之宝→神器。
- **记法铁律**：落档成品仍写「品阶」（下／中／上／极品），五境九品只作总阶定位（同功法「阶＋等」的位），一次只用一种，不得混写。

**品阶由五因素决定**：主材定境基｜器纹定品升｜器师境界定上限（不超自身两档）｜火候与机缘定浮动 ±一品｜器劫幸存可越一境。

## 五、主材·辅材·器引·淬火液

- **主材**：矿、木、骨、皮四类，**料龄阶不倒挂**（同药龄阶 TZ-0032）：料龄高 1／2／≥3 阶 → 品阶骰 ＋10／＋20／＋30，保底中／上／极品；高 ≥2 阶控温难度上浮一档，120 后不发生。
- **辅材**：定性（增韧、导灵、聚煞），可近似替代，−10% 且必带器戾。
- **器引**：点睛之引（妖兽精血、灵眼醇液、雷竹汁），缺器引绝不出极品；器引亦可以是「人」（㉕药引线的器道版）。
- **淬火液**：寒泉、地火、雷液、兽血，定最终料性走向，错液即废。
- **加减料**：减料（主材七成）−15%、至多中品绝不出极品；加料 −8%、上品以上概率翻倍。

## 六、丹道概念逐条对齐

| 丹道 | 器道 | 表现与应对 |
|---|---|---|
| 丹劫 | 器劫 | 高品出炉引雷火，渡过越一境，毁则成废器 |
| 丹灵 | 器灵 | 宝器以上生灵性，认主、自养；古宝多带残灵 |
| 丹毒 | 器戾 | 暴烈料性残留，蚀持用者心性；开锋、祭炼、高道心化解 |
| 废丹 | 废器 | 主材损，回收三成辅材 |
| 变异丹 | 异变法器 | 噬主／通灵／凶器三型，同「奇丹异药」功能／代价／异类三分 |
| 丹纹 | 器纹 | 威能 ＋一档、可越一境 |
| 杂毒·保质 | 戾气·蒙尘 | 法器久置灵性流失，须温养 |

## 七、世界观融合

- **同源**：两道皆「火候之学」，共用技艺熟练度池但分账（炼丹／炼器各记）；悟性同一口径入成功率公式。
- **互通**：器纹即微型阵法，阵法造诣可作地利项；看火眼力直接折入控温 T。
- **取舍**：炼丹耗药园与年份，炼器耗矿脉与地火，宗门建筑克制（丹房升则炼器阁吃紧）；一炉丹数日、一件器数旬，双修两道必分时间与灵石。
- **相成**：炼丹须好丹炉（器），炼器须淬火液与养器丹（丹）——**以丹养器、以器护丹**，两道互为买方；声名各自记账（丹香引客 ↔ 器鸣引客）。
