# 灵界玩法管家

## 〇、核心铁律（永久性，不得为叙事妥协）

1. **复用不重复**——灵界**不另写一套机制**。人界已有的机制（十章情报三档／十六章宗门经营／十七章地图探索／九章战斗三步／六章机缘押注）**全复用**，只做**换算**。
2. **飞升是换舞台，不是换游戏**——玩家手感不变，只有尺子变了。
3. **灵界一切都比人界更贵、更慢、更稀**——同样一件事，人界花一年，灵界花十年。
4. **种族大于个人**（灵界三大铁律之二）——宗门/地图/情报都受种族影响，不写成"无差别"。
5. **天劫不等人**（铁律之一）——不让玩家"攒够资源再渡劫"。
6. **飞升不可逆**（铁律之三）——不下放"回人界探亲"，那是凡人流不该有的爽点。
7. **「远方」不可丢**——人界尘缘跨界保留，是飞升后最阴的一手，不许图省事清零。
8. **大事件必进公证**——灵脉占领／遗迹大发现／部族覆灭／天劫／跨大陆／飞升仙界。

**发现要"新写一套灵界机制"时停手**，先问"人界有没有"。有就换算，没有就回去补人界机制，别在灵界单开。

## 三、天劫结算（复用五段 D100 + `灵界仙界篇.md` 3.4 天劫细则）

**结算三步**：

**第 1 步 · 算天劫强度**：
```
天劫强度 = 基础值（境界）＋ 累积（境界越深越重）＋ 道心加权 ＋ 痕加权
道心 ≥30 → 天劫 −5%
道心 ≤−60 → 天劫 +10%
痕越重 → 天劫越重（同 `xiuzhen-gm` 天劫公式）
寿元将尽再渡 → 天劫 +20%
```

**第 2 步 · 投 D100 五段**：
- 大成功 ≤5 → 天劫散去 + 道心 +1
- 成功 ≤阈值 → 渡过
- 部分成功 ≤阈值×1.5 → 渡过但**伤根基**（道基 −10、寿元 −10%）
- 失败 ＞阈值×1.5 → **重伤**（寿元 −30%、境界跌半阶）
- 大失败 ≥96 → **身死道消**

**第 3 步 · 存档与公证**：天劫前**必存档**（生死关必存档，走第 30 章存档块）。结果进 `天道秘录.md` 出公证 **TZ-00XX**（天劫／生死关，必进公证）。

## 八、灵界声名与尘缘

**声名**：从 0 起。人界声名清零（飞升是换舞台，人界的传说在灵界没人听过）。

**尘缘**：从 0 起算新名册。**人界尘缘不丢**——记在面板「远方：人界X人」。**不可互动**，**卷末小结写一笔**（"远方的南宫忠老矣"）。

**唯一例外**：人界「远方」亲友**仍可被当人质**（补遗一章尘缘规则跨界生效）。**飞升不等于了断**。

**增减规则不变**：相处一月 +1／亲友死亡 −1／亲手送终不变／十年不见 −1／主动断绝→「断」不可逆。**系统不可兑换尘缘**（跨界也不可）。
