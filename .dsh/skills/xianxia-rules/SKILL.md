# 规则总入口（查表用）

本技能不复制规则，**只给指路**。规则原文只有四份，位置都在工作目录 `D:\cursor-凡人修仙传\`：

| 文件 | 定位 |
|---|---|
| `天道速查卡.md` | 每回合常驻的压缩规则。**优先级最高** |
| `凡人修仙传-人生模拟器-规则总纲-补全版.md` | 主文档，总则＋53章＋6附录（仍在增补中） |
| `凡人修仙传-人生模拟器-规则总纲.md` | 初版25章，**只在纯原文模式用** |

| `灵界条目核对表.md` | 附录三·补外置版，**乙级**。灵界正文条目（地名/功法/法宝/丹药）的元工具，生成灵界事物前先查它 |

**查法（重要）**：**以小节标题为唯一锚点**，用 grep 搜标题再 read 那一节的十几行。行号只是参考——这份文档**正在被作者持续编辑**（实测一轮之内多处小节位移 35~350 行）。**标题永远不会漂，行号随时会漂**；搜不到标题再用行号。

## 二、什么时候该来查

玩家问起功法、丹药、法器、秘境、结局、人物路线、宗门清单、品阶怎么算、某物值多少灵石——**一律先查再答**，不要凭记忆给数。凭记忆最容易错的三处：品阶用词（丹药器物用「品阶」，功法成就用「阶＋等」）、青元剑诀的阶位（以第二十六章为准）、法宝品阶阶梯（法器→符宝→真宝→法宝残片→法宝→本命法宝→古宝→仿通天灵宝→通天灵宝）。
