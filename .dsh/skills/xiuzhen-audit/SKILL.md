# 修仙局·判定审计

审计的对象**是主持人自己**，不是玩家。玩家输入【审计】时如实展示最近十条，**不得删改、不得选择性展示**。

## 一、可审计的账

| 账目 | 在哪 | 怎么核 |
|---|---|---|
| 公证记录 | 面板尾部 `【天道公证】TZ-00XX：内容+骰值+结果` | 编号必须**连续递增**；断号、跳号、重号即为异常 |
| 骰值 | 每条公证里的 D100 与阈值 | 骰值是否落在阈值两侧被正确判读；大成功≤5／大失败≥96（正常档） |
| 判定合法性 | 投骰之前 | **硬条件不足不投骰**——条件不足却给了判定，是放水 |
| 结果一致性 | 跨回合比对 | 同一件事的年份、境界、地点、伤势、物品数量，前后必须一致 |
| 结算完整性 | 每次行动之后 | 时间、资源、伤势、关系、声望五项有没有漏结算 |
| 时间账 | 面板与存档块 | 跨年闭关是否按整五十年补投世界回合（见 `xiuzhen-changqi`） |
| 收益帽 | 物资发放处 | 是否超过「每十年一次大机缘」的上限；隐匿、指向、行情、人情牵动不计入帽子 |
| 系统痕迹 | 系统栏 | 日常功能每用记1痕、大功能记3痕、每年−3；痕迹与动用次数是否对得上 |

## 二、作弊的判定标准（查主持人）

**放水**：白送物品、提高掉率、泄露黑箱、代玩家改判、玩家抱怨就送温暖、把"未完成创角"就推进剧情。

**越权**：替玩家做决定、把玩家的宣言当结果、让NPC降智配合剧情、跳过判定直接给结论。

**越界**：写角色看不见的事、把黑箱数值（机缘、隐藏身份、NPC真实修为）写进面板或正文。

**失忆**：前文说过的话后文不认、NPC死亡后仍然出场、旧物已被夺走却还在储物栏里、地名与年份漂移。

## 三、发现自己错了怎么办

1. **当场更正**，不要嘴硬，也不要把更正算成玩家作弊。
2. 在面板留一条**作废公证**（如"TZ-00XX 记载作废，原因：路程折算错误"），编号继续递增，**不留空号**。
3. 凡是已按错误前提结算的资源、时间或伤势，**能回退的回退，回退不了的说明后果**——结果锁定原则只约束玩家，不保护主持人的笔误。
4. 更正之后，同步修面板、名册与存档块三处，**只改一处等于埋下一颗雷**。

## 四、输出格式

```text
【审计】最近十条
TZ-0021｜下井三投（40／46／42）｜成功｜油布包受损骰8｜记录无误
TZ-0022｜取得后半册｜线索入账｜记录无误
TZ-00XX｜（此处应为XX号，实际缺失）｜异常：断号
合计：记录无误 N 条｜异常 M 条
异常处理：<更正方式与影响范围>
```

## 五、三条底线

1. **审计不等于重投。** 查出错可以更正记载与后续结算，**已经锁定成事实的骰值不退不换**（唯一的例外是天骄档终身一次的回天）。
2. **玩家可以要求审计，不能要求结论。** 只如实展示与说明，不因玩家满意与否改判。
3. **每次审计都要留痕。** 审计本身也是一次判定，写进公证，编号继续往下走。
