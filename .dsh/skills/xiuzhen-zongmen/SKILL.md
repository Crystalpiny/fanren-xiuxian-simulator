# 宗门经营管家

> **职责边界**：本技能只管**宗门运转机制**（收支/弟子/建筑/事件/战争/覆灭）。**设定数据**看补全版十三章；**生成新宗门的规矩**看 43.4；**战斗结算**用九章战斗三步定式；**NPC 名册**用三十二章。
>
> **复用不重复**：本技能不复制规则，只做**入口与索引**。规则原文仍是唯一权威。

---

## 1. 核心铁律（执法红线）

1. **宗门不是爽文基地**——不得给玩家"白送弟子""白送资源""白送建筑"
2. **半年一投不可跳过**——每 6 个月一次宗门事件；闭关跨年补投
3. **收支必须公示**——每半年公示收入、支出、赤字、事件骰
4. **弟子必须自愿**——不得生造"抓壮丁"式收徒
5. **建筑不能样样都强**——每升一级必有短板被拉长（43.4 第 1 条）
6. **大事件必进公证**——宗门覆灭、灵脉枯竭、宗主陨落 → TZ-00XX
7. **与因果·道心挂钩**——按 16.11 结算，不得漏
8. **不玩家管理**——宗门是长线投资，不是经营模拟器

## 4. 半年一投结算流程（每 6 个月）

```
1. 结算收入：弟子供奉 / 坊市抽成 / 任务奖励 / 药园产出
2. 结算支出：弟子月俸 / 建筑维护 / 丹药供给 / 大阵灵石
3. 投弟子成长：D100 按天赋+资源决定进境
4. 投宗门事件：D100 表（16.6）
5. 检查赤字：半年不补 → 弟子忠诚 −10；一年不补 → 弟子流失 1~3
6. 结算因果/声名/尘缘/道心（16.11）
7. 大事件 → 进公证（TZ-00XX）
```

## 7. 宗门战争（复用九章战斗三步）

1. **战力比**：宗门综合实力（弟子+建筑+灵脉）÷ 敌方
2. **档位表**：≥3.0 碾压／2.0~2.9 优势／1.3~1.9 上风／0.8~1.2 均势／0.5~0.7 劣势／<0.3 碾压
3. **三档结局**：胜／胜有代价／负

**战后四件套**（九章 9.4）：**结仇 + 失友 + 夺宝 + 抬声名**，四件事同时结算。

**大事件必进公证 TZ-00XX**。

## 9. 与现有机制挂钩（16.11）

| 机制 | 挂钩 |
| --- | --- |
