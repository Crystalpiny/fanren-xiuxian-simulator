# 修仙局·多世轮回管家

治的是同一件事：**死不是结束，是下一世的开局。** 所有跨世的账必须落成文字，落在**轮回小结**与**轮回图鉴**里。核心铁律：**业力不以善恶论**——轮回不问正邪，只问「你这一世活得有多用力」。

规则原文在 `凡人修仙传-人生模拟器-规则补遗.md` **十五、多世轮回**，本技能只写**何时做、怎么落地**，数值一律按原文。

## 一、核心铁律（先读这条，再动手）

**业力不以善恶论**。玩家「选恶」不扣出身、不加心魔；「选善」也不给出身、不减心魔。**唯一依据是道心**。

- **心魔跟善恶无关，跟坚定有关**：魔修杀到底 = 道心 60+ = 心魔 **−10%**；魔修摇摆不定 = 道心 −30 = 心魔 **+10%**
- **魔修是合法路线**：天道不劝善也不劝恶；NPC 可以有常人的善恶反应
- **因果记纠缠不问善恶**：杀人和救人都是 +3；善行另有善缘事件（规则补遗二十章）。**数值表里没有「善恶」这一栏**

## 二、双轴跨世结算

原文：`### 15.2 双轴一：因果纠缠`｜`### 15.3 双轴二：道心`｜`### 15.4 心魔跨世 = 道心决定`

### 2.1 因果纠缠（决定下世故事密度，不决定出身）

善恶行为都加因果点，**数值一律以补遗 15.2 归口总表为准（TZ-0034），散章数值不得随手用**：救人性命 +3／杀无辜 +3／灭门 +10（灭门必引强因果反噬）／背信 +3／夺宝 +2／传功 +2／守信 +1／济世 +2／**隐世修行或闭死关 −2/年**。临场情节按 15.2 三档裁定（大 +3~+10／中 +1~+2／小＝0 单纯知情不记账）。

**消因按了因果表（TZ-0034）**：报恩还命 −3／赔偿失宝 −2／归还赃物赔罪 −2~−3／替死者了事 −2／守诺十年 −1／化解仇怨 −5／超度收葬 −1（一人一次年上限 −3）／闭死关 −2/年——须有对家、一笔只销一次、不入收益帽。**因果点只记债不再是货币**（兑天机付天机签）。

下世事件密度：**≥30 高**（恩人仇家一大把）／**0~29 中**／**≤−30 低**（清净，韩立式生存）。

### 2.2 道心（决定下世资质）

道心值 −100~+100，初始 0。坚持一条道走到底 **+5**／悟道 **+2**／中途改道 **−3**／摇摆不定 **−5**／道心破碎（走火入魔/心魔失控）**−10**。

下世出身与心魔：

| 道心 | 出身 | 悟性 | 心魔抵抗 | 突破成功率 |
| --- | --- | --- | --- | --- |
| ≥ 30 | 好 | +N | −10% | +5% |
| 0~29 | 普通 | 0 | 无 | 0 |
| ≤ −30 | 差 | −N | +10% | −5% |
| ≤ −60 | 极差/妖物/魔道遗孤 | −2N | +25% | −10% |

N = ⌈|道心值| ÷ 10⌉。

## 三、轮回小结（十项，一世终结必写）

原文：`### 15.8 轮回小结（十项，一世终结时必写）`

| # | 项 | 用途 |
| ---: | --- | --- |
| 1 | 一世最终境界 | 决定道果总值 |
| 2 | 一世最终因果点 | 决定下世事件密度 |
| 3 | 一世最终道心值 | 决定下世出身/悟性/心魔抵抗 |
| 4 | 一世最终痕 | 跨世累积 |
| 5 | 一世机缘境界（0~10） | 决定道果 4 偏移 |
| 6 | 一世气运境界（0~10） | 决定道果 5 偏移 |
| 7 | 一世技艺（四类熟练度） | 决定道果 6 数值 |
| 8 | 一世修炼造诣（最终境界＋功法圆满数） | 决定道果 2 修行记忆档位 |
| 9 | 一世成就（成就墙条目） | 决定道果 7 品质 |
| 10 | **一世死因** | 道心微调：战死 +2／走火入魔 −5／飞升 +10 |

**十项漏算漏结视为失忆**（同出关四写）。**写进【轮回图鉴】，不写进【公证】**——公证是本世的账，轮回是跨世的账。

## 四、道果承载点

原文：`### 15.5 七项道果详解`｜`### 15.6 道果承载点系统`

### 4.1 承载成本

业力 10／道心 15／机缘 15／气运 15／悟道 20／技艺 25／传承 30。**七项总和 130**。

### 4.2 道果总值（按最终境界）

飞升 **150**（七项全带）／大乘 130／合体 120／炼虚 115／化神 110／元婴 100／结丹 90／筑基 70／炼气 50。

### 4.3 分配规则

1. **一次性分配**，用不完不补
2. **同一项不能重复选**（无「双份道心」）
3. **可以不选**（成就「赤子」）
4. **飞升必选传承**（遗物品质最高，且是后续剧情钩子）

### 4.4 修行记忆（道果② · TZ-0356 起取代「残卷记忆」）

原文：`### 15.12 前世修行记忆`。**转世不带功法，只带过程**——前世功法的文字一个字不记得，记得的是怎么修、怎么行气运气、怎么用战技、怎么闯关。

**三档**（转世时按上世造诣定档，不投骰；境界与功法圆满数**取高**；每世重定档不累加）：

| 档 | 定档 | 情境 N |
| --- | --- | ---: |
| 点滴 | 未至结丹，且无功法修至圆满 | +3 |
| 历练 | 结丹～元婴，或 1 部功法修至圆满 | +5 |
| 圆融 | 化神及以上，或 2 部以上功法修至圆满 | +8 |

- **四处顺畅（只走情境）**：功法修习（月进度记 +N%）／行气运气／战技施展／突破心得。有 T 改 T +N 不改五段，无 T 记 +N% 情境
- **三条不给**：不给功法内容／不给身手（跨世清零）／不给前世人事（旧梦只给意象，不给信息）
- **两条代价**：旧路掣肘（今世功法与上世主修**异路**时吃不到加成）／旧梦（修到旧关口起梦，是因果钩子，不送情报）
- **旧账**：TZ-0356 前已带的残卷记忆 % 保留不改史，但**记忆残页线冻结止步**；功法改走「推残卷·实物」。残卷推演的「推修行心得」见 `规则补遗-系统篇.md` 29.18

## 五、下世开局（重抽）

原文：`### 15.9 与现有机制挂钩`

| 机制 | 跨世行为 |
| --- | --- |
| 五维 | **不清零，重抽**（按出身）；只有道果 1/2/4/5 给偏移 |
| 身手 | **清零**（换身重修；修行记忆只给战技施展的顺畅，不给身手值） |
| 修行记忆（道果②） | **只记过程不记内容**（4.4）；每世按上世造诣重定档，不累加 |
| 尘缘（第六维） | **不清零，跨世继承** |
| 声名 | **清零**（转世没人记得你）；道果 6「技艺」可触发声名 +2 |
| 因果点 | **跨世结算，累计不清零** |
| 痕 | **跨世累积**（系统的债越积越多） |
| 系统（17 项池） | **本身不跨世**（每世新抽）；但痕会找上门 |
| 心魔 | **跨世累积**（按道心加成/减成） |

**下世出身按道心重抽，事件密度按因果决定**。

## 六、防刷三道锁

原文：`### 15.7 无上限轮回 + 三道锁`

**轮回次数无上限**（玩家裁定「不设终局」）。

| 锁 | 机制 | 防什么 |
| --- | --- | --- |
| 1. 每世从头修 | 境界、寿元、灵根清零/重抽 | 防「攒一世就无敌」 |
| 2. 道果承载有限 | 按成就给点，飞升才全带 | 防「无限堆道果」 |
| 3. 心魔/因果跨世累积 | 道心低 → 心魔重；因果多 → 故事多 | 防「数值失控」 |

**不做轮回商店**——太 gamey，破坏凡人流基调。轮回奖励只走**道果**一条路。

## 七、元进程维护

- **轮回图鉴**：每世记录出身、结局、道果、因果、道心
- **轮回成就**：九世不同出身／不同结局／道心平衡／极致因果／极致清净／**赤子**（不带道果）／**贪**（七项全带）

## 八、天道守则（执法红线）

原文：`### 15.11 天道守则`

1. **业力不以善恶论**——不得因玩家「选恶」扣出身、加心魔，也不得因「选善」给出身、减心魔
2. **因果记纠缠不问善恶**——救人 +3，杀人 +3，灭门 +10（灭门必引强因果反噬）。**数值表里没有「善恶」这一栏**
3. **魔修是合法路线**——天道不劝善也不劝恶；NPC 可以有常人的善恶反应
4. **轮回无上限**——不得设终局，不得给「九世之后强制结算」
5. **道果承载是奖励**——不得做成惩罚机制（玩得差不是惩罚，是没奖励）
6. **轮回小结必写十项**——漏算漏结
7. **不写进【公证】**——轮回是跨世的账，公证是本世的账
8. **系统不跨世但痕跨世**——转世后系统是新的，但痕会找上门

## 九、玩家常问的三句（怎么答）

| 玩家问 | 答 |
| --- | --- |
| 「我做好事下世会不会好点？」 | 出身看**道心**；善行带来人脉、善缘、传闻这些别的回报——下世的起点一样看**道心** |
| 「恶业让我心魔变重吗？」 | **不会**。心魔看**道心坚定度**。摇摆不定才心魔重 |
| 「轮回有上限吗？」 | **没有**。三道锁防刷：每世从头修／道果承载有限／心魔与因果跨世累积 |
| 「转世还记不记得上一世的功法？」 | **不记得**（TZ-0356）。带的是**修行过程记忆**——点滴 +3／历练 +5／圆融 +8，作用于功法修习、行气运气、战技施展、突破心得四处；功法文字一个字不带，要重新寻实物或走「推修行心得」与推残卷补出 |
