# 修仙局·长线管家

治的是同一件事：**局开得越久，前文越靠不住。** 所有跨时间的账都必须落成文字，落在存档块、名册与卷末小结里。**飞升是最大的跨时间断点**——第六节的解锁流程就是为这一刻准备的。

规则原文在 `凡人修仙传-人生模拟器-规则总纲-补全版.md`，本技能只写**何时做、怎么落地**，数值一律按原文。

## 一、世界时钟（每一个世界回合 = 五十年）

原文（按**编号 + 标题前缀** grep，**不看行号**——文档在持续编辑）：`### 31.2 五十年推演表`｜`### 31.3 固定大事件`｜`### 31.4 出关三写`｜`### 31.6 世界回合与玩家回合的换算`

每个世界回合投一次 D100，按 31.2 表出结果并公示编号。**玩家闭关、疗伤、游历跨年时，按跨越的整五十年数补投**——世界不会因为玩家不出场就停摆。

出关必写**四**样，缺一不可：**物证、传闻、后果、凡俗亲友状态**，且至少有一次**不可逆的失去**（故人已逝／旧地已毁／旧物易主）。

第四样是补遗新增的强制项：凡俗亲友的现状——谁老了、谁病了、谁走了、谁嫁了、谁还在等你。每次闭关 ≥1 年必写。**跳过视为漏结算**。存档块【人际】栏须记尘缘值与亲友状态（见 `规则补遗.md` 一、尘缘）。

固定大事件（4500~4520正魔大战、4526韩立结丹、4530虚天殿、4617韩立结婴、4630昆吾山、4650天南大战）**不能被玩家阻止**，只能选择站队、脱身或远走；开局年若已过某事件，该事件改为已发生的历史，须写出物证与余波。

## 二、存档块（跨线程的唯一凭据）

原文（按**编号 + 标题前缀** grep）：`### 30.2 存档块格式`｜`### 30.3 存档时机`｜`### 30.4 新线程恢复流程`｜`### 30.7 简版存档`

**存档时机（强制）**：每十年一次简档；每次境界突破后全量档；每卷结束与卷末小结合并输出；玩家输入【存档】【存档·简】随时可存，**不得拒绝**；玩家长时间不回复或临离开前，天道主动存一次。

**续玩四步**：贴存档块 → 天道复述确认（年份、境界、所在地、所在卷与目标、三件未了之事）→ 补一段"这些年发生了什么"（按世界时钟推进）→ 进正常回合。**存档块与面板冲突时以存档块为准**；存档块缺字段须逐项向玩家确认，**不得自行编造**。

**防篡改**：存档块携带公证编号链，与【审计】记录互相印证。玩家手改数值，天道比对后须指出不一致并要求说明；无正当缘由按作弊处理，黄牌起算。

## 三、NPC 名册（防"前面那个人哪去了"）

原文（按**编号 + 标题前缀** grep）：`### 32.1 名册字段`｜`### 32.2 老化与成长`｜`### 32.3 继位与传承`｜`### 32.4 重逢规则`｜`### 32.5 名册维护与呈现`

- 名册字段：姓名／道号｜修为｜立场｜性格（三字以内）｜动机（一句话）｜与玩家的关系＋好感｜最后见面年份｜状态｜备注。
- 每世界回合更新一次：按境界投死亡或失踪概率（炼气15%／筑基10%／结丹5%／元婴2%／化神1%），**每人另投一次 D100**（01~40不变／41~70进一小层／71~85衰老或受伤／86~95重大变故／96~100触发死亡判定）。
- **死亡的NPC不移除**，只标状态与年份——留给回首与墓志铭。
- 每卷至少安排一次"物是人非"的重逢，写清**外貌变化、境界变化、关系变化**三件。
- 【名册】只列重要NPC（5~8人为限），其余按需展开。

## 四、卷末小结（封卷时一次做完）

原文（按**编号 + 标题前缀** grep）：`### 33.4 卷末小结`｜`### 33.3 每卷的节奏要求`

固定六项，照此结构输出，**并与存档块合并**：① 本卷大事记（三至五条）② 得失清单 ③ 关系变化（谁死了、谁上位、谁结仇）④ 未了伏笔（三至五条）⑤ 存档块 ⑥ 下一卷预告（一句话，只给钩子）。

每卷节奏硬指标：一次不可逆的失去、一次"得大于失的机会"逼取舍、两名新NPC与一个新势力、一次舞台更换（地点／势力／身份）。

## 五、收尾自查

1. 年份对得上吗？面板、存档块、名册三处的年份必须一致。
2. 上次闭关跨了多少年？跨了整五十年就要补投世界回合，投了吗？
3. 这一卷有没有不可逆的失去？没有就是没写完。
4. 名册里死亡的人还在场吗？死了就标年份，不许复活。
5. 存档块的公证编号是否接得上上一次？断号就是篡改。
6. **凡俗亲友状态写了吗？** 尘缘与声名记进存档块【人际】栏了吗？（补遗强制项，漏了视为漏结算）
7. 人质触发了吗？（尘缘 ≥6 时每次结仇掷 D100，≥15 触发"亲友被挟"事件线）
8. **境界跨化神了吗？** 跨了就走第六节的解锁流程，不要让灵界内容提前泄进人界。

## 六、灵界解锁流程（飞升切换）

`灵界仙界篇.md` 人界阶段禁读；三个查表技能（`xianxia-rules` / `xianxia-world` / `xianxia-chars`）的灵界/仙界小节一律禁读。**解锁的触发与切换全在本节**，不得由玩家宣告解锁。

### 6.1 触发条件（任一即触发）

- **修为触发**：化神后期巅峰 + 渡过飞升雷劫（天劫公式按补全版"元婴/化神突破"节）
- **剧情触发**：被灵界/仙界势力接引、召见、传送、流放
- **主动触发**：玩家明确申报"破界飞升"并承担代价（人界所有尘缘转为「远方」，不可逆）

触发时**先公示一条**：`【天道公告】天南历X年X月，XXX破界飞升——人界篇收口，灵界篇开启。`

### 6.2 天道立刻做五件事（顺序不可换）

1. **卷末小结**（见第四节六项）——人界最后一卷，**必须做完整六项**，不得以"赶进度"为由跳过
2. **人界封档**：把人界存档块整体存为"人界封档"（`存档-人界-终.md`），只读不改
3. **新线起手**：以灵界修为、灵界所在、灵界状态开新存档块，头部写"人界封档引用：<文件路径>"
4. **技能解锁**：三个查表技能的灵界/仙界小节解锁；`灵界仙界篇.md` 现在可读
5. **面板刷新**：境界字段扩至灵界阶位，寿元字段按灵界寿元重设，声名归 0（见 6.4）

### 6.3 解锁清单

| --- | --- | --- |

### 6.4 跨界保留 / 清零

| 项目 | 处理 | 理由 |
| --- | --- | --- |
| **因果点 / 因果签 / 痕** | **保留** | 系统资源跨界面结算 |
| **机缘骰 / 机缘历史** | **保留** | 押注与逆押的连续性 |
| **尘缘** | **转「远方」**（不可逆） | 不再每月互动，只在卷末小结写一笔；灵界尘缘按新名册从 0 起算 |
| **声名** | **归 0**（人界声名转为"传说"） | 灵界没人认识你；只在人界故人重逢时作为背景加成 |
| **声望（正/魔/散修/盟约）** | **归 0** | 同声名 |
| **境界 / 修为** | **保留** | 硬通货 |
| **身家（灵石、法宝、丹药）** | **保留**（品阶按灵界汇率折算） | 具体折算由天道按补全版"物价表"节处理 |
| **功法 / 神通** | **保留** | 但品阶上限按灵界阶位解锁 |

### 6.5 二次解锁（仙界）

仙界触发条件：灵界阶段化神巅峰（或仙界篇指定阶位）+ 渡仙劫/接引。流程与 6.2 一致，只是"人界"全换成"灵界"。**人界封档继续保留不改**，作为整局的根。

### 6.6 天道守则

- 解锁**必须**由天道发起，不得因玩家宣告而提前
- 飞升前**必须**做完整卷末小结——这是人界篇的唯一句号
- 灵界/仙界内容**不得**在人界阶段泄出（哪怕玩家问起，也只给"传闻"档模糊指引）
- 玩家若试图"带着人界资源直接跳灵界后期"，按**作弊**处理（第二十二章）
