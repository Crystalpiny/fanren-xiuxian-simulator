# 修仙局·NPC 与地点生成

原文（按**编号 + 标题前缀** grep，**不看行号**——文档在持续编辑）：`### 38.2 姓名与道号`｜`### 38.3 性格与动机`｜`### 38.4 地名生成`｜`### 38.5 洞府生成`｜`### 38.6 悬赏与宗门任务生成`｜`### 38.7 连贯性检查`

用法：`### 38.1 使用规则`——**投骰 → 组合 → 一次成型**，生成后立即登入名册（见 `xiuzhen-changqi`）。

## 一、掷骰次序

1. **姓**：D100（单姓80／复姓20）
2. **名**：按性别取男名或女名表，D100 各一万种组合；**同一宗门同辈共用字辈**，可再叠字成三字名
3. **道号**（修士才有）：特征 D20 ＋ 后缀 D10
4. **性格** D20、**动机** D20、**身份** D20——三者一次投齐
5. 需要场景时：**地名** = 前缀 D20 ＋ 后缀 D10；**洞府** = 位置／禁制／守护／遗留各投 D6；**悬赏** = 目标／赏金／发布方／暗坑各投 D6；**宗门任务** = 类型 D10 ＋ 暗坑 D6

以上各表的实际条目一律读原文对应小节，**不要凭记忆编**。

## 二、成型的四条硬规矩

- **气味要对**：姓氏朴实、道号不中二、动机利己而具体。**越凡俗的名字越短**，不要"傲天""无双""红尘仙"那类说书人的名号。
- **地名要像**：同一片山水的名字总是像的——同地区前缀重复率应偏高，不要一村一个风格。
- **动机要能推动行为**：动机栏决定这个NPC下一步干什么。写不出"他会因此做什么"的动机，重投。
- **必须查重**：与既有名册、与前文出现过的名字**不得重名**。NPC 重复姓氏可以，重复姓名不行；重名会让玩家误以为是旧人。

## 三、连贯性检查（38.7，必做）

生成后自问三句，**三问答不上来就重投一次**：

1. 此人为何在此？
2. 他靠什么活着？
3. 他与玩家已有的人际是否会发生冲突？

## 四、落地要求

- 每个有名字的NPC都要有**要什么、怕什么、手里有什么牌**三件，缺一件就不算成型。
- 生成即登入名册：姓名｜修为｜立场｜性格｜动机｜关系与好感｜最后见面年份｜状态。
- **修为只给区间，不给准数**（黑箱）；NPC真实修为不得写进玩家能看见的面板。
- 掉落、赏金、暗坑都要落成世界内的实物与人情，**不得直接改判定数值**。

## 五、与其它技能的边界

生成归本技能；生成之后的时间推进、老化、死亡与重逢归 `xiuzhen-changqi`；NPC 的台词与神态由 `xianxia-voice` 写。**三者的数字必须一致**——名册里的境界，不能和正文里写的境界打架。
